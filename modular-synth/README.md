# Witchwave — модульный синтезатор для телефона

Компактный веб-синтезатор на **Web Audio API**: стеллаж модулей, патч-кабели,
сенсорная клавиатура и пресеты. Работает прямо в мобильном браузере
(никакой сборки, чистые HTML/CSS/JS).

## Запуск

Любой статический сервер, например:

```bash
cd modular-synth
python3 -m http.server 8080 --bind 0.0.0.0
```

## Модули

| Модуль | Что делает | Входы |
|---|---|---|
| VCO 1 / VCO 2 | Генераторы (SIN/TRI/SAW/SQR), частота, октава, дитюн, FM | FM |
| LFO | Модуляционный осциллятор, rate/depth | — |
| ENVELOPE | ADSR, управляет громкостью/фильтром | — |
| NOISE | Белый шум | — |
| VCF · LP | ЛП-фильтр с резонансом | IN, CUT (CV), RES (CV) |
| VCA | Усилитель (ADSR сюда) | IN, GAIN (CV) |
| MIX | 3 входа с уровнями | IN1–IN3 |
| MASTER OUT | Объём, компрессор, индикатор | IN |

## Установка на телефон (PWA)

Приложение — **Progressive Web App**: его можно поставить на рабочий стол как обычное приложение.

- **iPhone (Safari):** открыть страницу → «Поделиться» (квадрат со стрелкой) →
  «На экран „Домой“». Появится иконка Witchwave, открывается в полноэкранном режиме.
- **Android (Chrome):** открыть страницу → меню ⋮ → «Установить приложение» /
  «Добавить на главный экран».

После установки:
- свой значок (неоновая волна + ручки) и название **Witchwave**;
- полноэкранный режим без адресной строки;
- **офлайн-режим** — service worker (`sw.js`) кэширует всё приложение;
- патчи, сохранённые через SAVE, хранятся в localStorage и переживают перезапуск.

> Иконки лежат в `icons/` (any + maskable), Apple-иконка — `apple-touch-icon.png`.
> Перегенерировать иконки: `python3 make_icons.py` (нужен Pillow).

## Как играть

1. **Тапни «ТАПНУТЬ, ЧТОБЫ ВКЛЮЧИТЬ»** — браузер разрешит звук.
2. Играй на клавиатуре внизу (мульти-тач, можно «скрипеть» по клавишам).
3. **Кабели:** провод можно начинать от светящегося вывода (OUT) или перетягивать
   с любого конца — за сокет или за сам провод. Отпустить в сокет — подключить,
   на другую точку — сменить выход, в воздухе — снять.
4. **Rучки:** вращай свайпом вверх/вниз, двойной тап — сброс к значению по умолчанию.
5. **OCT ±** — октавы клавиатуры, **HOLD** — удержание звука,
   **RND** — случайный патч, **SAVE/LOAD** — сохранить/загрузить свой патч (localStorage).

## Пресеты

- **Классика FM** — saw → фильтр → VCA, энвайра на громкость.
- **Пад ведьмы** — два осциллятора через MIX, медленный ADSR, LFO на FM.
- **Тёмный бас** — энвайра модулирует cutoff, резонансный фильтр.
- **Шумовой лид** — шум + square через MIX.

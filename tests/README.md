# Тесты

Смоук-тесты логики запускаются в jsdom: реальные `index.html` и `game.js`
исполняются в эмуляции браузера, canvas и звук подменяются заглушками.

```bash
npm install --no-save jsdom
node tests/game.test.js
```

Проверяется 92 сценария: старт, лес, провалы и уход гостя, подсказки за монеты,
улучшения, достижения, сохранение (в том числе перезагрузка в середине варки),
битые сохранения, рестарт, полный цикл всех десяти рецептов, клавиатура,
анимированный кадр и PWA-файлы.

## Пицца апокалипсиса

Логика новой игры тестируется встроенным раннером Node без зависимостей:

```bash
node --test tests/pizza-engine.test.js
```

UI-тесты используют jsdom:

```bash
npm install --no-save jsdom
node --test tests/pizza-ui.test.js
```

Проверяются старт/пауза/рестарт, русская раскладка по физическим кодам клавиш,
удержание огня и нитро, автопауза при потере фокуса, сохранение и санитизация
рекордов, экран проигрыша, доступные клики по кнопкам и настройка звука.

PWA-проверки не требуют зависимостей:

```bash
node --test tests/pizza-pwa.test.js
```

Проверяются манифест, размеры PNG-иконок, ссылки в HTML, список офлайн-кэша и
регистрация service worker.

# Греем Мотор — Автономный новостной ИИ-агент и оформление ВК

Полностью автономный облачный ИИ-агент и фирменный пакет оформления для сообщества **«Греем Мотор»** (**[https://vk.ru/greem_motor](https://vk.ru/greem_motor)**), работающий **бесплатно через GitHub Actions без собственного сервера**.

Агент сам просыпается по расписанию, мониторит автомобильные СМИ и новости Ярославля (76 регион), выбирает лучший свежий инфоповод или тему полезного авторазбора, пишет живой авторский пост с лёгкой водительской иронией, вычитывает его через второй проход ИИ-корректора, рисует уникальную ИИ-иллюстрацию через **GigaChat (Kandinsky)** и сразу публикует запись от имени группы на стену ВК.

---

## Что умеет агент

- **Умный поиск и фильтрация 8 источников**:
  - Автомобильные издания: *Колёса.ру*, *5 колесо*, *Motor.ru*, *Drom.ru* (включая корректное чтение `windows-1251`).
  - Локальная повестка **Ярославля и 76 региона**: *76.ру* и региональный поиск (строгий фильтр пропускает только авто, дороги, ГИБДД, мосты, пробки и трассу М-8 — никакого шоу-бизнеса и посторонних тем).
  - Подборки советов водителям, юридических разборов ПДД/ОСАГО и обслуживания авто с пробегом.
- **Чередование рубрик («Автоновости» + «Полезно водителю»)**:
  - Публикует горячие автоновости с практическим выводом для автомобилиста.
  - Каждый 3-й выпуск (а также если в ночной/тихий час нет громких новостей) готовит экспертный разбор или сезонный лайфхак по обслуживанию, выбору б/у авто и эксплуатации в условиях Ярославской области.
- **Тройная защита от дублей**:
  1. По нормализованным ссылкам (без `utm`-меток) и `guid`.
  2. По смысловой близости заголовков (если 5 разных СМИ написали про одну и ту же новость, агент выберет самую полную версию с лучшим фото и **не опубликует** её повторно из другого источника).
  3. Прямая сверка с последними постами на стене `vk.ru/greem_motor` через `wall.get` (даже если администратор выложил новость вручную, бот не повторит её) + автосохранение истории в `vk-news-agent/state/published.json`.
- **Собственные ИИ-иллюстрации без чужих фото (`image_mode: "ai_only"`)**:
  - Для каждого поста **GigaChat (`text2image` / Kandinsky)** создаёт уникальную автомобильную иллюстрацию по теме с лёгкой доброй визуальной иронией (0% скачанных чужих фото из СМИ и 0% рисков по ст. 1259/1301 ГК РФ).
  - Встроенная защита промпта от визуальных ошибок ИИ: строго без надписей, искажённых букв/цифр, дорожных вывесок и госномеров.
  - Если сервис генерации изображений временно недоступен, агент подставляет собственную студийную карточку рубрики из `branding/cards/`.
- **Лёгкий водительский юмор + двухэтапная вычитка без ошибок (`proofread_posts: true`)**:
  - Живая подача с уместной доброй водительской иронией (без выдуманных фактов и без шуток в темах ДТП/перекрытий).
  - Второй независимый проход ИИ-корректора (`temperature=0.15`) проверяет орфографию, пунктуацию, склонение числительных и автомобильную терминологию.
- **Чистое оформление под алгоритмы ВКонтакте**:
  - Никаких «сырых» звёздочек Markdown (`**`, `###`), выдающих бота.
  - Без внешних ссылок в теле поста (чтобы умная лента ВК не резала охваты), с подписью адреса сообщества `vk.ru/greem_motor` и аккуратными фирменными хештегами `#грееммотор #грееммотор76 #greem_motor #автоярославль #авто76`.

## Быстрый запуск за 5 минут (без сервера)

### Шаг 1. Получите токен ВКонтакте (`VK_TOKEN`)

> **Важная особенность VK API для картинок:**
> ВКонтакте разрешает загружать фотографии на стену (`photos.getWallUploadServer` → `photos.saveWallPhoto`) **только по токену пользователя-администратора группы**. Обычный «ключ доступа сообщества» из настроек группы умеет публиковать текст (`wall.post`), но на загрузку картинок возвращает ошибку `Error 27`.

Выберите удобный вариант:

1. **Рекомендуемый вариант (посты + автозагрузка фото на стену):**
   - Получите бессрочный токен пользователя, который является администратором группы `vk.ru/greem_motor`, с правами **`wall, photos, groups, offline`** (проще всего через [vkhost.github.io](https://vkhost.github.io/) — нажмите **«Настройки»**, отметьте галочки `Стена`, `Фотографии`, `Группы`, `Доступ в любое время` и в списке приложений выберите **Kate Mobile**, затем скопируйте из адресной строки часть между `access_token=` и `&expires_in`).
   - Сохраните этот токен как секрет **`VK_TOKEN`** — он сам определит ID группы `greem_motor`, загрузит картинку и опубликует запись **строго от имени группы** (`from_group=1`), без имени личного аккаунта.
   - *(Опционально)* Если хотите разделить права: в `VK_TOKEN` можно положить ключ самого сообщества, а токен админа — в `VK_USER_TOKEN`.
2. **Упрощённый вариант (только текст без загрузки фото):**
   - Откройте `https://vk.ru/greem_motor` → **Управление** → **Работа с API** → **Ключи доступа** → **Создать ключ** (отметьте доступ к стене сообщества) и положите его в **`VK_TOKEN`**. Агент автоматически увидит, что это ключ сообщества, и будет публиковать аккуратные текстовые посты без сбоев.

---

### Шаг 2. Получите ключ нейросети (работают из РФ без VPN)

Достаточно настроить **любую одну** нейросеть — агент определит её автоматически:

#### Вариант А: Сбер GigaChat (есть бесплатный пакет токенов для физлиц)
1. Зайдите в кабинет разработчика Сбера: **[developers.sber.ru/studio](https://developers.sber.ru/studio)** (вход по Сбер ID).
2. Создайте проект **GigaChat API** (тариф для физлиц `GIGACHAT_API_PERS` даёт бесплатные токены без привязки карты).
3. Нажмите **«Получить ключ»** и скопируйте **Authorization Key** (длинная строка в Base64).
4. Добавьте её в секреты GitHub под именем **`GIGACHAT_AUTH_KEY`**.

#### Вариант Б: YandexGPT (Yandex Cloud)
1. Зайдите в консоль **[console.yandex.cloud](https://console.yandex.cloud/)** и скопируйте **ID каталога** (`folder_id`, например `b1g...`) → это секрет **`YANDEX_FOLDER_ID`**.
2. В разделе **Сервисные аккаунты** создайте сервисный аккаунт с ролью **`ai.languageModels.user`**.
3. Внутри сервисного аккаунта нажмите **Создать новый ключ → Создать API-ключ** и скопируйте секретный ключ (`AQVN...`) → это секрет **`YANDEX_API_KEY`**.

---

### Шаг 3. Добавьте секреты в репозиторий GitHub

Откройте ваш репозиторий на GitHub → **Settings** → **Secrets and variables** → **Actions** → кнопка **New repository secret**:

| Имя секрета | Обязателен? | Что вставить |
|---|---|---|
| `VK_TOKEN` | **Да** | Токен администратора группы ВК с правами `wall,photos,groups,offline` (или ключ сообщества) |
| `GIGACHAT_AUTH_KEY` | **Да** *(или YandexGPT)* | Authorization Key из кабинета Сбер GigaChat Studio |
| `YANDEX_API_KEY` | Альтернатива GigaChat | API-ключ сервисного аккаунта Yandex Cloud |
| `YANDEX_FOLDER_ID` | В паре с `YANDEX_API_KEY` | Идентификатор каталога Yandex Cloud |
| `VK_GROUP` | Нет (по умолчанию `greem_motor`) | Можно не указывать — группа `https://vk.ru/greem_motor` уже настроена по умолчанию |
| `VK_USER_TOKEN` | Нет | Нужен только если в `VK_TOKEN` лежит ключ сообщества, а фото нужно грузить отдельным токеном |

Также во вкладке репозитория **Settings → Actions → General → Workflow permissions** убедитесь, что выбран пункт **Read and write permissions** (чтобы агент мог сохранять список уже опубликованных новостей в `vk-news-agent/state/published.json`).

---

### Шаг 4. Протестируйте и включите автопостинг

1. Перейдите во вкладку **Actions** репозитория на GitHub.
2. Выберите слева workflow **«Греем Мотор — Новостной ИИ-агент ВК»** *(а для однократной установки шапки, аватарки, описания, закрепа и переписывания прошлых постов — workflow **«Греем Мотор — Оформление группы ВК (в 1 клик)»**)*.
3. Нажмите **Run workflow**:
   - Для безопасной проверки поставьте галочку **`dry_run`** → агент соберёт реальные автоновости, напишет пост и покажет готовый текст и размер картинки прямо на странице отчёта запуска (**Summary**), ничего не отправляя в ВК.
   - Уберите галочку **`dry_run`** и нажмите **Run workflow** → свежий пост с картинкой сразу выйдет на стене **[vk.ru/greem_motor](https://vk.ru/greem_motor)**!

По умолчанию агент запускается **автоматически 3 раза в день**:
- **~08:15 МСК** — утренний выпуск
- **~13:15 МСК** — дневной выпуск
- **~19:15 МСК** — вечерний выпуск

## Настройка расписания, источников и стиля

- **`vk-news-agent/config.json`** — все RSS-ленты, ключевые слова Ярославля (76 регион), стоп-слова от рекламы, хештеги и база тем рубрики «Полезно водителю».
- **`.github/workflows/vk-news-agent.yml`** — расписание `cron` в формате UTC (МСК = UTC + 3).
- Локальный запуск с компьютера (требуется только Python 3.11+, **ноль внешних pip-зависимостей**):
  ```bash
  python3 vk-news-agent/agent.py --dry-run --allow-template-fallback
  ```

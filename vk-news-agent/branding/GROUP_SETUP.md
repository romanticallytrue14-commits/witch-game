## 🔑 Почему ключ группы (`VK_TOKEN`) не загружает аватарку и фото постов — и как включить их за 1 минуту

API ВКонтакте блокирует методы загрузки фотографий (`photos.getWallUploadServer` и `photos.getOwnerPhotoUploadServer`) для ключей сообщества (**ошибка VK API `27: method is unavailable with group auth`**), но разрешает их для **пользовательского токена администратора (`VK_USER_TOKEN`)**.

Чтобы **и аватарка группы, и фотографии во всех постах (включая догрузку фото к уже вышедшим постам!)** заработали автоматически:

1. Откройте [vkhost.github.io](https://vkhost.github.io/) → нажмите **«Kate Mobile»** → нажмите **«Разрешить»**.
2. Скопируйте из адресной строки браузера часть после `access_token=` и **до** символа `&` (начинается с `vk1.a....`).
3. В репозитории откройте **`Settings → Secrets and variables → Actions → New repository secret`**:
   - **Name**: `VK_USER_TOKEN` *(свой текущий `VK_TOKEN` удалять не нужно — они работают в паре!)*
   - **Secret**: вставьте скопированный токен `vk1.a....`
4. Зайдите во вкладку **`Actions` → «АвтоТочка — Оформление группы ВК (в 1 клик)» → `Run workflow`**:
   - Скрипт автоматически установит **круглый аватар `avatar.jpg`**, обновит **статус**, прикрепит **баннер `pinned_post.jpg`** к приветственному посту и **автоматически догрузит фотографии к недавним постам на стене**!

> 💡 Альтернатива для аватарки вручную (за 10 секунд): откройте `https://vk.ru/autoyar076`, наведите курсор на кружок аватара → «Обновить фотографию» и выберите файл `vk-news-agent/branding/avatar.jpg`.

## 🤖 Как проверить ключ Сбер GigaChat (`GIGACHAT_AUTH_KEY`)

В **Sber Studio** (`developers.sber.ru/studio` → проект GigaChat API → **Настройки API**):
- Поле **`Client ID`** (короткий UUID из 36 символов вида `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`) — это **только ID проекта**, а не ключ авторизации (с ним сервер Сбера возвращает `401 Authorization error: header is incorrect`).
- Нажмите кнопку **«Получить новый ключ»** — появится длинный **`Authorization key`** (~100 символов Base64, обычно заканчивается на `==` или `=`).
- Обновите секрет **`GIGACHAT_AUTH_KEY`** в `Settings → Secrets and variables → Actions`, вставив туда этот длинный `Authorization key`.

# Пицца апокалипсиса

Браузерные гонки на выживание с юмором и экшеном. Мир рухнул, заказы — нет.
Веди курьерскую машину по четырём полосам, расстреливай зомби-такси пицца-пушкой,
собирай припасы и продержись как можно дольше.

Игра полностью статическая: без сборки, зависимостей и регистрации.
Открой `index.html` двойным кликом или подними любой статический сервер:

```bash
python3 -m http.server 3000 --directory pizza-apocalypse
```

## Установка на телефон

Постоянная ссылка: **https://romanticallytrue14-commits.github.io/witch-game/pizza-apocalypse/**

Игра поддерживает установку как PWA: ярлык на главном экране, отдельное окно
и офлайн-режим после первой загрузки. Нужна HTTPS-ссылка, открытая в обычном
браузере телефона, а не во встроенном окне чата.

1. Открой ссылку игры на телефоне и нажми **«На телефон»** в шапке.
2. Дождись статуса **«Офлайн-копия готова»**.
3. Нажми **«Установить»**, если браузер показал кнопку, или следуй инструкции:
   - **Android / Chrome:** меню `⋮` → «Установить приложение» / «Добавить на главный экран».
   - **iPhone / Safari:** «Поделиться» → «На экран “Домой”» → «Добавить».

Адрес `127.0.0.1` или `localhost` работает только на том компьютере, где запущен
сервер. Для телефона нужна публичная ссылка предпросмотра или опубликованная копия
игры. Ссылка предпросмотра может быть временной; для постоянной установки лучше
разместить статические файлы на HTTPS-хостинге.

## Правила

- Бензин тратится постоянно. Канистра даёт **+28**, чаевые-пицца — **+6** и 250 очков.
- Прочность теряется при столкновениях. Изолента чинит **+30**.
- Нитро ускоряет машину и сносит препятствия на твоей полосе. Батарея даёт **+40 нитро**.
- Пицца-пушка уничтожает препятствия, но не трогает припасы.
- Серия уничтожений повышает множитель очков до **×5**; ошибка или пауза в серии сбрасывает его.
- Каждые 750 метров открывается новый район, движение становится плотнее, скорость растёт.
- Заезд заканчивается при нулевой прочности или пустом баке. Топ-5 результатов сохраняется в браузере.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Перестроение | `←` / `→` или `A` / `D` | кнопки `←` / `→` или свайп по дороге |
| Пицца-пушка | удерживай `Пробел` | удерживай кнопку «Пицца-пушка» |
| Нитро | удерживай `Shift` | удерживай кнопку «Нитро» |
| Пауза | `P` / `Esc` | кнопка паузы в шапке |
| Старт / рестарт | `Enter` | кнопка на экране |

Физические коды клавиш: русская раскладка не мешает управлению.
При потере фокуса или сворачивании вкладки игра автоматически встаёт на паузу.

## Особенности

- Canvas-рендер с псевдо-3D дорогой, частицами, взрывами и процедурными машинами.
- Web Audio-звук без файлов и автовключения: создаётся только после жеста пользователя.
- `prefers-reduced-motion`: без тряски, вспышек и декоративных частиц.
- Локальный шрифт Oswald и SVG-иконки: никаких внешних запросов.
- Рекорды и настройка звука хранятся в `localStorage`; повреждённые данные безопасно игнорируются.
- PWA: `manifest.webmanifest`, `sw.js`, PNG-иконки и кнопка «На телефон».
- Офлайн-кэш имеет префикс `pizza-apocalypse-` и не удаляет кэши других игр.

## Файлы

- `index.html` — интерфейс, экраны, HUD и SVG-иконки.
- `style.css` — адаптивная тёмная тема.
- `engine.js` — чистая игровая логика без DOM, тестируется в Node.
- `game.js` — рендер, ввод, звук, рекорды и игровой цикл.
- `install.js` — установка на главный экран, копирование ссылки и офлайн-статус.
- `manifest.webmanifest`, `sw.js` — PWA и офлайн-кэш.
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` — иконки.
- `assets/` — локальный шрифт и лицензия.

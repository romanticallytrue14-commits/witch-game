# Witchbeat — карманная драм-машина

Создавай биты на телефоне: все 16 шагов видны одной линией, четыре четвертные
доли 4/4 отмечены поверх сетки. В секвенсоре 10 дорожек: пять ударных, TB-303,
пианино, орган, струнные и колокольчик. Удерживай шаг любой нотной дорожки, чтобы
менять ноты; фильтр и резонанс TB-303 настраиваются отдельно. Звуки создаются
через Web Audio API без аудиофайлов. Текущий грув можно отрендерить в WAV (четыре
такта) и скачать на устройство. На телефоне звук запускается после касания
«Играть» — браузеры блокируют автозапуск аудио. Приложение работает офлайн.

## Запуск

Открой `index.html` через любой статический сервер. Например, из корня репозитория:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Затем открой `http://localhost:8080/drum-machine/`. Для офлайн-режима и установки
PWA нужен HTTPS или `localhost`.

## Возможности

- Все 16 шагов одновременно в одной линии; четверти сгруппированы по четыре
  шестнадцатых шага в размере 4/4.
- 10 дорожек: бас-бочка, малый барабан, закрытый и открытый хэты, хлопок,
  TB-303, пианино, орган, струнные и колокольчик.
- Удерживай шаг любой нотной дорожки, чтобы включить его и циклически менять
  ноту; нажатие по названию дорожки прослушивает звук.
- Управление фильтром и резонансом TB-303, четыре готовых грува, случайный ритм,
  очистка сетки и экспорт текущего паттерна в WAV на четыре такта.
- Темп 60–180 BPM, Tap Tempo, свинг и общая громкость.
- Автосохранение паттерна в `localStorage`.
- PWA-манифест, собственные иконки и offline cache.

Для сохранения нажми **WAV**: после рендера нажми появившуюся кнопку ещё раз,
чтобы скачать файл. Паттерн по-прежнему автоматически сохраняется в браузере на
этом устройстве.

На iPhone открой сайт в Safari и выбери «Поделиться» → «На экран Домой».
На Android открой меню Chrome и выбери «Установить приложение».

## Файлы

- `index.html`, `style.css` — интерфейс и адаптивная мобильная тема.
- `engine.js` — чистые функции паттернов, санитаризация и рандомизация.
- `app.js` — интерфейс, синтез звука, WAV-рендер и сохранение.
- `wav.js` — PCM16/WAV-энкодер.
- `sw.js`, `manifest.webmanifest`, `icons/` — установка и офлайн-режим.
- `make_icons.py` — генератор PNG-иконок без сторонних библиотек.

Смоук-тесты модели и PWA-файлов: `node --test tests/drum-machine.test.js` из корня репозитория.

Небольшая браузерная игра без сборки и зависимостей: ведьма варит зелья для гостей
у края тёмного леса. Открывается двойным кликом по `index.html` или через любой
статический сервер. Устанавливается как приложение (PWA) и работает офлайн.

## Правила

- Гость просит зелье. **Рецепт скрыт**: известны только название, награда и то,
  чем зелье «пахнет». Пахнет оно ингредиентами, которые в него входят.
- Нужно положить в котёл **ровно два ингредиента** и сварить зелье.
- Удача → монеты и +1 заказ. Ошибка → ингредиенты сгорают, у гостя остаётся
  одна попытка. Вторая ошибка — гость уходит, серия успехов сбрасывается.
- Серия успешных заказов подряд даёт бонус: +1 🪙 за каждый заказ, максимум +5.
- Первое удачное зелье **открывает рецепт в гримуаре** — потом его видно в списке.
- 🕯 Подсказка раскрывает один ингредиент текущего заказа за 4 🪙.

## Управление

| Действие | Мышь / палец | Клавиатура |
|---|---|---|
| Положить ингредиент | кнопка ингредиента | `1`–`4` |
| Сварить зелье | «Сварить зелье» | `Enter` |
| Очистить котёл | «Очистить котёл» | `Esc` |
| Подсказка | «Подсказка» | `H` |

## Лес

| Тропа | Что даёт |
|---|---|
| 🌾 Опушка | обычный ингредиент (гриб, трава или ягода) |
| 🌲 Чаща | риск: 16% — ничего, 36% — 🌙 лунный цветок, 48% — обычный ингредиент |

| Достижение | Условие |
|---|---|
| Первый гость | сварить первое зелье |
| Твёрдая рука | пять заказов подряд без ошибок |

## Файлы

- `index.html` — разметка: сцена, гость, лес, котёл, гримуар, лавка, достижения.
- `style.css` — тёмная «сказочная» тема, сетка статистики, адаптив, reduced-motion.
- `game.js` — вся логика: состояние, рецепты, экономика, достижения, сохранение,
  звук, клавиатура и canvas.
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png` — установка и
  офлайн-режим.

## Технические заметки

- Прогресс хранится в `localStorage` под ключом `witchGame3`; старый ключ
  `witchGame2` читается один раз для миграции. Котёл сохраняется вместе с запасом,
  поэтому ингредиенты не теряются при перезагрузке.
- Загруженные данные проходят санитизацию: битые числа, чужие ингредиенты,
  неизвестные рецепты, улучшения и достижения отбрасываются, игра не падает.
- Звук — Web Audio без файлов: низкий гул-фон, аккорд на удачу, глухой тон на провал,
  отдельная фанфара на достижение. Включается только по кнопке.
- При `prefers-reduced-motion: reduce` сцена рисуется одним статичным кадром,
  анимация и вспышки отключаются.
- Service worker работает по стратегии network-first: в сети всегда свежие файлы,
  без сети — копия из кэша. Регистрация только по http(s), поэтому с `file://`
  игра тоже запускается, просто без офлайна.
